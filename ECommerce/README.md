# Ecommerce

Este proyecto corresponde a un sistema de ecommerce dividido en frontend y backend.

De forma general, el sistema permite gestionar la experiencia de una tienda en linea, incluyendo:

- navegacion publica de productos
- autenticacion de usuarios
- manejo de roles
- operaciones asociadas a compras y gestion interna

## Estructura general

- `front-end/`: aplicacion cliente desarrollada en React
- `Back-end/`: API desarrollada en Django y Django REST Framework
